# Danaini phylogeny data

This folder contains the phylogenetic input and output files used to generate the Danaini phylogeny for Extended Data Figure 1 in February 2026. Because NCBI records and intermediate retrieval outputs may change over time, this repository includes the final trimmed locus alignments, concatenated supermatrix, partition files, IQ-TREE outputs, final tree, and accession table used in the manuscript.

Included files:

- `trimmed/` — final trimmed locus alignments
- `supermatrix.fasta` — concatenated 6,585-bp alignment
- `partitions.csv` and `partitions_codon.nex` — partition files
- `Danaini_concat.treefile` — IQ-TREE maximum-likelihood tree
- `Danaini_concat.iqtree` and `Danaini_concat.log` — IQ-TREE output files
- `Supplementary_Data_1.csv` — GenBank accession table
