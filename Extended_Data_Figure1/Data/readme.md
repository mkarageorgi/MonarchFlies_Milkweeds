## Data associated with code for Extended data Figure 1


The R markdown file 1_prepare_hostplant_data.Rmd generates:

plant_butterfly_long_all.csv: Curate dataset containing butterfly taxonomy, host-plant taxonomy, host-association records, cardenolide occurrence, and ATPα state information.   

The R markdown file 2_prepare_danaini_phylogeny.Rmd generates files found in the ./Danaini_phylogeny folder.

The R markdown file 3_reconstruct_hostplant_associations.Rmd requires as input files:
- plant_butterfly_long_all.csv:  Curated butterfly–host plant association dataset generated by `1_prepare_hostplant_data.Rmd`.
- Danaini_concat.treefile: Maximum-likelihood Danaini phylogeny generated by `2_prepare_danaini_phylogeny.Rmd`.
- 1041_Fishbein et al. 2018[outgroups_removed].newick:  Time-calibrated Apocynaceae phylogeny originally from Fishbein et al. (2018), accessed through the Dryad archive associated with Nürk et al. (2021): `Nuerk_etal2021_Apocynaceae_FrontEcolEvol.zip`, Dryad DOI `10.5061/dryad.vq83bk3sj`.
- moraceae_genus.nwk:  Genus-level Moraceae tree obtained from TimeTree.
