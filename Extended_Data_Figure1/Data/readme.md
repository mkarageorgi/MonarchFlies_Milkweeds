## Data associated with code for Extended data Figure 1


- The script 1_prepare_hostplant_data.Rmd generates:

plant_butterfly_long_all.csv: Curate dataset containing butterfly taxonomy, host-plant taxonomy, host-association records, cardenolide occurrence, and ATPα state information.   

- The script 2_prepare_danaini_phylogeny.Rmd generates files found in the ./Danaini_phylogeny folder including:
Danaini_concat.treefile — IQ-TREE maximum-likelihood tree

- The script 3_reconstruct_hostplant_associations.Rmd requires as input files:
  - plant_butterfly_long_all.csv:  Curated butterfly–host plant association dataset generated by `1_prepare_hostplant_data.Rmd`.

- Danaini_concat.treefile: Maximum-likelihood Danaini phylogeny generated by `2_prepare_danaini_phylogeny.Rmd`.

- 1041_Fishbein et al. 2018[outgroups_removed].newick: Published Apocynaceae phylogeny used to derive the genus-level Apocynaceae tree.

- Apo_Mora_phylo_tree/moraceae_genus.nwk:  Genus-level Moraceae tree obtained from TimeTree.
