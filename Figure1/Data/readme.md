## Data associated with code for Extended data Figure 1

The R markdown file 4_hostplant_phylogenetic_signal.Rmd requires as input files:
- plant_butterfly_long_all.csv: the curated butterfly–host plant association dataset containing butterfly taxonomy, host-plant taxonomy, host-association records, cardenolide occurrence, and ATPα state information.
- danaini_species_final_tree.newick: the pruned and rooted Danaini phylogeny used to estimate Pagel’s λ for milkweed-clade host use
It generates:
- pagel_lambda_milkweed_phylo_signal.txt`: the Pagel’s λ estimate and likelihood-ratio test output.
